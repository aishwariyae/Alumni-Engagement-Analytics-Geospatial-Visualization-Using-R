# Alumni-Engagement-Analytics & Geospatial-Visualization-Using-R
Performed R-based analysis of a 16K+ alumni dataset by cleaning, merging, and analyzing demographic and geographic data across state and city levels. Applied descriptive statistics, proportion analysis, and geospatial visualization techniques to identify engagement trends and support strategic alumni outreach initiatives.

# Overview
This project analyzes alumni distribution across the United States to identify optimal locations for future alumni engagement events using statistical and geospatial analysis in R. The study was conducted in collaboration with the Department of Alumni Relations at Emmanuel College and involved mentoring two student researchers throughout the analytical process.

Using a dataset containing over 16,000 alumni records, the project explored geographic clustering patterns across states, cities, and metropolitan regions to support data-driven event planning and stakeholder decision-making.

# Research Objective
The goal of this project was to:
1. Analyze alumni population distribution across the U.S.
2. Identify high-density and underserved alumni regions
3. Support strategic planning for future alumni events using statistical and geospatial insights

# Dataset
The dataset consisted of approximately 16,292 records and 5 variables, including:

* Alumni state
* Graduation year
* ZIP code
* Preferred city
* Geographic location information

# Tools & Technologies
+ R Programming
+ ggplot2
+ usmap
+ dplyr
+ Exploratory Data Analysis (EDA)
+ Choropleth Mapping
+ Statistical Aggregation & Distribution Analysis

# Methodology
1. Data Preparation
2. Cleaned and structured alumni demographic and geographic data
3. Aggregated alumni counts across states, cities, and metropolitan regions
4. Exploratory & Statistical Analysis
5. Conducted descriptive statistics and proportion analysis
6. Identified top states and cities based on alumni concentration

Performed hierarchical geographic analysis at the:
* State level, City level, Metropolitan level
* Geospatial Visualization
* Built choropleth maps using ggplot2 and usmap
* Represented alumni density across U.S. states using gradient-based color scaling
* Visualized top metropolitan hubs and alumni distribution trends

# Key Findings
1. Massachusetts contained the highest concentration of alumni (~10,000 alumni)
2. New Hampshire emerged as a statistically significant and previously underserved alumni hub
3. Nearly 50% of New Hampshire alumni resided in:
  + Manchester
  + Nashua
  + Salem
    
  A majority of alumni in these cities belonged to the School of Humanities and Social Sciences

# Impact
The analysis provided stakeholders with data-driven insights for strategic alumni engagement planning and helped identify New Hampshire as a high-potential location for future alumni events.
